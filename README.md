Description of R scripts to simulate and analyze data under three scenarios:
Scenario 1: Misspecification of a fixed initial elevation at the first occasion as absent
Scenario 2: Misspecification of a fixed, exponentially decaying IE as confined to the first occasion 
Scenario 3: Misspecification of a random, exponentially decaying IE as fixed 

A detailed summary of the simulation study: "Summary Monte Carlo Data Simulation" pdf
